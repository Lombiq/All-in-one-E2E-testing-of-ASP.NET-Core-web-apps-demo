# "All in one E2E testing of ASP.NET Core web apps with UI/security/accessibility tests" demo

Demo codebase used for the [.NET Conf 2026 talk](https://www.dotnetconf.net/agenda#session-D4T20261113043000) "All in one E2E testing of ASP.NET Core web apps with UI/security/accessibility tests" and more.

> Do you have an ASP.NET Core web app and make sure that it works? You can use the open-source UI Testing Toolbox to do all that: with the power of Selenium for browser UI tests, axe for checking accessibility, Zed Attack Proxy for security scans, and many more tools built in, it's a complete package. See all of this in action with plenty of (C#) code!

Interested in learning more about the tools used in this demo? Check out the [Lombiq UI Testing Toolbox for Orchard Core](https://github.com/Lombiq/UI-Testing-Toolbox)!
